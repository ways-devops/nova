# Nova CRM

Персональная CRM для привлечения и сопровождения клиентов бухгалтерского аутсорсинга.
Стек: Next.js 15, TypeScript, Tailwind CSS 4, PostgreSQL, Prisma, PWA.

## Статус: Этап 4 — интеграции выполнен

Готово:
- структура проекта, конфигурация Next.js / TypeScript / Tailwind
- полная схема БД (User, Lead, Client, Deal, Task, Conversation, Message, Integration, Activity)
- закрытая авторизация email + пароль (bcrypt, JWT в httpOnly-cookie, лимит попыток входа)
- защита всех маршрутов через middleware (API без сессии отвечает 401)
- навигация: боковое меню на компьютере, нижняя панель на телефоне
- Dashboard с реальными счётчиками из БД (пока пустыми)
- PWA: manifest, иконки, service worker, страница «Нет соединения»

Этап 2:
- заявки: создание, редактирование, поиск (имя, телефон, компания, город, комментарий), фильтры по статусу и источнику
- карточка заявки: смена этапа, заметки, история изменений, объединение повторных заявок по телефону
- воронка: канбан с перетаскиванием карточек между этапами (на телефоне — выпадающий список на карточке)
- переход в «Потеряна» требует причину; переход в «Стал клиентом» создаёт клиента с согласованной стоимостью
- клиенты: список, MRR, карточка с редактированием и историей

Этап 3:
- задачи: название, срок, приоритет, привязка к заявке или клиенту; группы «Просрочено / Сегодня / Позже»; отметка выполнения, перенос на +1 день, удаление
- блок задач прямо в карточках заявки и клиента
- главная: счётчики, прогресс к цели (5 клиентов, 50 000 ₽ MRR), последние обращения, ближайшие задачи, лента действий, диаграмма источников, предупреждение о просроченных задачах
- аналитика: эффективность источников (заявки, клиенты, конверсия, MRR), воронка, причины потерь, динамика за 6 месяцев; период 30/90 дней, год, всё время
- история действий: создание и выполнение задач попадают в ленту заявки и клиента

Этап 4:
- Telegram: уведомления о новом обращении, новом сообщении, новом клиенте и напоминания о задачах (в момент наступления срока)
- Авито: приём сообщений (webhook и/или опрос каждые 2 минуты), автоматическое создание заявки, хранение диалога, ответы из CRM
- защита от дублей: внешний ID сообщения и диалога уникален; сообщение считается отправленным только после подтверждения API Авито
- раздел «Сообщения»: список диалогов, непрочитанные, чат с ответом
- Настройки: проверка Telegram и Авито, поиск chat id, ручная синхронизация, диагностика webhook
- фоновые задачи работают внутри приложения (`src/instrumentation.ts`), отдельный cron не нужен

## Запуск на Mac

Нужны Node.js 20+ и Docker Desktop.

```bash
cd nova-crm
npm install

cp .env.example .env
# откройте .env и задайте:
#   AUTH_SECRET     — openssl rand -base64 48
#   ADMIN_EMAIL     — ваш email для входа
#   ADMIN_PASSWORD  — пароль, минимум 10 символов

npm run db:up        # PostgreSQL в Docker
npm run db:migrate   # создать таблицы (имя миграции: init)
npm run db:seed      # создать единственного пользователя
npm run dev          # http://localhost:3000
```

## Проверка PWA

Service worker включается только в production-сборке:

```bash
npm run build
npm run start
```

Для установки на iPhone приложение должно открываться по HTTPS
(Safari → Поделиться → На экран «Домой»). Это станет возможно после этапа 5 (VPS + домен).

## Обновление до этапа 4

```bash
npm run db:migrate    # новая миграция: непрочитанные в диалогах (имя: messages_unread)
```

Добавьте новые переменные из `.env.example` в свой `.env` и **перезапустите** `npm run dev`
(планировщик стартует вместе с приложением).

## Подключение Telegram

1. В Telegram найдите @BotFather, команда `/newbot`, получите токен → `TELEGRAM_BOT_TOKEN` в `.env`.
2. Напишите своему боту любое сообщение.
3. Перезапустите приложение, откройте Настройки → «Найти chat id», вставьте число в `TELEGRAM_CHAT_ID`.
4. Перезапустите приложение, нажмите «Отправить тест».

## Подключение Авито

1. В личном кабинете Авито откройте раздел для разработчиков (developers.avito.ru), создайте приложение и получите
   Client ID и Client Secret → `AVITO_CLIENT_ID`, `AVITO_CLIENT_SECRET`. Доступ к Messenger API
   может требовать отдельного разрешения Авито — это нужно уточнить в кабинете.
2. Перезапустите приложение, Настройки → «Проверить подключение».
3. Без публичного адреса работает опрос: «Синхронизировать сейчас» или автоматически раз в 2 минуты.
4. После развёртывания (этап 5) задайте `APP_URL` (https), `AVITO_WEBHOOK_SECRET` и нажмите «Подключить webhook» —
   сообщения будут приходить сразу, а опрос останется страховкой.

Интеграция с Авито написана по документации Messenger API без проверки на реальном аккаунте.
Если формат ответа окажется иным, все адреса запросов собраны в `src/features/avito/client.ts`,
а последнее событие webhook видно в Настройках.

## Важно

- Регистрации нет: пользователь создаётся только командой `db:seed`.
- Смена пароля: измените `ADMIN_PASSWORD` в `.env` и снова выполните `npm run db:seed`.
- Лимит попыток входа хранится в памяти процесса — подходит для одного сервера.
- Токен Авито хранится в таблице `Integration` на сервере; публичный адрес webhook защищён секретом.
- `.env` не коммитьте (он в `.gitignore`).
